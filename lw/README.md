# Лабораторный практикум по дисциплине «Основы машинного перевода»

**МГПУ — направление 44.03.05 «Педагогическое образование (с двумя профилями подготовки)»**  
Профиль: **«Информатика и английский язык»**

Практикум построен как сквозной кейс: студент локализует небольшой англоязычный обучающий модуль по информатике и на четырех этапах последовательно создает терминологические ресурсы, выполняет нейросетевой и LLM-перевод, а затем оценивает качество и трудозатраты на постредактирование.

## Структура

1. [Лабораторная работа 1. Компьютерная лексикография, терминологические базы (TBX) и Translation Memory (TMX) в Smartcat](lab_01.md)
2. [Лабораторная работа 2. Нейросетевой перевод на базе Hugging Face Transformers (MarianMT, NLLB)](lab_02.md)
3. [Лабораторная работа 3. Контекстный перевод и локализация с помощью LLM (GigaChat / YandexGPT API / OpenSource LLM)](lab_03.md)
4. [Лабораторная работа 4. Автоматические метрики (BLEU, chrF, COMET) и экспертная оценка постредактирования (MTPE / MQM)](lab_04.md)

## Единая шкала

Каждая лабораторная работа оценивается **ровно в 20 баллов**.

| Компонент | Баллы |
|---|---:|
| Работоспособность пайплайна / кода | 6 |
| Корректность лингвистической обработки и валидации | 5 |
| Анализ ошибок и аргументация решений | 5 |
| Оформление репозитория и reproducibility | 4 |
| **Итого за лабораторную** | **20** |
| **Итого за практикум** | **80** |
