# Sample educational module: Functions and Parameters

A function is a reusable block of code that performs a specific task.

A parameter is a name listed in the function definition.

An argument is a value passed to a function when the function is called.

The `return` statement sends a result back to the caller.

A local variable is available only inside its function scope.

Students should predict the output before running the program.

```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)
```

Compare a parameter with an argument and explain the difference.

Use a descriptive function name.

Do not change the function signature in this exercise.

A default argument is used when the caller does not provide a value.

A docstring describes the purpose and expected use of a function.

Recursion occurs when a function calls itself.

Before submitting the task, test the function with at least three inputs.
