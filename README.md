# Основы машинного перевода

Учебный курс для направления **44.03.05 «Педагогическое образование (с двумя профилями подготовки)»**, профиль **«Информатика и английский язык»**.

Курс знакомит студентов с основными этапами развития машинного перевода — от систем на основе правил (RBMT) и статистического машинного перевода (SMT) до нейросетевых архитектур (NMT), Transformer и современных LLM-подходов. Отдельное внимание уделяется компьютерной лексикографии, Translation Memory, форматам TMX/TBX, CAT-системам, постредактированию и автоматической оценке качества перевода.

Практическая часть построена как сквозной проект локализации англоязычного учебного материала по информатике с использованием Smartcat, Hugging Face Transformers, MarianMT/NLLB, GigaChat, Yandex AI Studio или локальных LLM, а также метрик BLEU, chrF, COMET и экспертной оценки MQM/MTPE.
